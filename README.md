# 氨氮显色图像分析系统

这是一个可部署到 Streamlit Community Cloud 的在线网页应用。用户无需在本地安装 Python。

## 部署步骤

1. 登录 GitHub，创建一个新仓库（Repository），例如 `ammonia-color-analysis`。
2. 将本文件夹中的 `app.py`、`requirements.txt`、`README.md` 上传到仓库根目录。
3. 打开 https://share.streamlit.io/ 并使用 GitHub 登录。
4. 选择 **Create app**，选择刚才的仓库、分支（通常是 `main`）和主文件路径 `app.py`。
5. 点击 **Deploy**。部署完成后会生成一个 `https://....streamlit.app` 网址。

## 使用方法

- 上传一张或多张显色照片。
- 左侧调整圆片半径和检测灵敏度。
- 核对自动识别的圆片编号。
- 按编号输入浓度，单位 g/L。
- 选择颜色指标并查看线性拟合，下载 CSV。

## 重要限制

- 自动圆片检测需要用户核对，复杂反光、圆片重叠或背景纹理可能造成漏检/误检。
- 不同拍摄条件的照片不能不经校正就混合拟合。建议固定光源、距离、曝光、白平衡，并在画面中加入颜色参考卡。
- R² 高不等于方法准确。应使用独立标准样品、重复实验和参考分析方法验证准确度、精密度、检出限及线性范围。
- 请核实标准液浓度单位和实际配制浓度。此应用中的浓度单位默认按用户输入的 g/L 显示，不会自动换算。
